# Threat models

STRIDE threat models per component / data flow. One file per component, named
`<component>.stride.md`, produced with the `stride-threat-modeling` skill
(`.claude/skills/stride-threat-modeling/`).

Start with the money-transfer flow (see `docs/context/06-threat-model-stride.md`).
Every High/Medium threat must yield a testable Definition-of-Done check before the
corresponding code is considered done.
